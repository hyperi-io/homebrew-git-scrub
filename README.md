# homebrew-git-scrub

Homebrew tap for [git-scrub](https://github.com/hyperi-io/git-scrub).

## Install

```bash
brew tap hyperi-io/git-scrub
brew install git-scrub
```

Or in one step:

```bash
brew install hyperi-io/git-scrub/git-scrub
```

## Maintenance

The `Formula/git-scrub.rb` file in this repository is **auto-generated** by
the release workflow in
[hyperi-io/git-scrub](https://github.com/hyperi-io/git-scrub) on every
release. Do not hand-edit — your changes will be overwritten on the next
release.
